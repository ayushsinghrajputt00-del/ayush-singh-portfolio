# Ayush Singh — Personal Portfolio

A responsive luxury editorial portfolio built with React, Vite and Framer Motion.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy on Vercel
Import this repository into Vercel. Use `npm run build` as the build command and `dist` as the output directory.

## Personalise
Update the biography, education, focus areas and public contact links in `src/main.jsx`. Add authentic projects to the Selected Work section as they are ready. No fictional clients, awards or metrics are included.
